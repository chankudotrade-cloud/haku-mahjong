# 1人用 白マイティ麻雀

1シャンテンに強くなるための練習ゲームです。

- 白はオールマイティです。
- 7枚・10枚はチートイツなし
- テンパイしたら必ずリーチしてください
- 一番多い待ちを選んでください
- フリテンリーチは禁止です
- 役はありません
- カンはできません
- 鳴きはできません
ブラウザだけで動く静的Webアプリ（Vite + TypeScript、UIは素のDOM）。

## 使い方

```powershell
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト（Vitest）
npm run build    # dist/ に静的ファイルを出力
```

`dist/` は相対パス（`base: './'`）で出力しているので、GitHub Pages のどのパスに置いても動く。
`.github/workflows/deploy.yml` を使う場合は、リポジトリの Settings → Pages → Source を
「GitHub Actions」にして main へ push する。

## 牌画像

`public/pai/` の牌画像は [麻雀王国 麻雀素材](https://mj-king.net/sozai/) のもの
（縦向き `_1`・横向き `_3`・白 `p_no_*`・裏 `p_bk_1`）。
素材の規約：「ご自由にお使いください。連絡は必要ありません（リンクもしくは出典表示は感謝いたします。）
改造、再配布なども問題ありません。著作権を放棄するものではありません。」
オープニング画面に出典リンクを表示している。

## 構成

| パス | 内容 |
|---|---|
| `src/core/tiles.ts` | 牌の定義（Kind 0-28 が山の牌、29 が白）・山・乱数 |
| `src/core/hand.ts` | アガリ判定・分解・待ち計算・無限単騎・フリテン（純粋関数） |
| `src/core/review.ts` | 1巡ごとの打牌候補の評価（最善打牌・テンパイ逃し） |
| `src/core/game.ts` | 1局の進行（状態機械）。時間は UI が管理し、時間切れで `timeout()` を呼ぶ |
| `src/core/settings.ts` | 秒数などの設定値と範囲、時間切れで切る牌の位置 |
| `src/core/stats.ts` | 成績の集計 |
| `src/storage.ts` | localStorage（try/catch 付き） |
| `src/ui/` | 画面（オープニング・対局・終了・局後レビュー）とドラッグ＆ドロップ |

## 仕様上「仮」の点・実装で決めた点

- 手牌の枚数（白を含む配牌）：オープニングで 7・10・13枚から選ぶ（初期値7、選択は保存）。アガリ形は 8枚＝2面子＋雀頭 / 11枚＝3面子＋雀頭 / 14枚＝4面子＋雀頭
  - 13枚のときだけチートイツもアガリ：種類の違う対子7組（同じ牌4枚は2組にしない）。白は1枚の牌と組んで対子になれる
  - 無限単騎：白を除いた牌がすべて面子の形。13枚では対子6組＋白も含む（リーチすればフリテンで終了）
  - 8枚の4トイツ、11枚の対子5組＋1枚はアガリではない
  - 手牌の牌の大きさは、手牌の枚数と画面幅から自動で決める
- 牌の数：手牌の枚数の下で 1色・2色・3色 から選ぶ（初期値3色、選択は保存）。3色＝萬筒索108枚 / 2色＝筒索72枚（萬子抜き） / 1色＝筒子36枚
  - 待ちは山にある種類だけで数える（1色は9種・2色は18種。無限単騎の待ちも同じ）
- 成績は 手牌の枚数×色数（9通り）ごとに記録する。以前の形式の成績（枚数ごと・枚数で分ける前）は3色の分として引き継ぐ
  - オープニングの成績は常に表示。「成績クリア（13枚・2色 など）」ボタンで、選んでいる組み合わせの成績だけを確認のうえ消す
- 牌構成：字牌はツモらないルール。山は数牌だけ（發・中は入れない）
- 相手の打牌：こちらが捨ててから0.5秒待って捨てる（`src/ui/app.ts` の `OPPONENT_DELAY`）
- 自分のツモ：相手が捨ててから（リーチ後はスルーしてから）0.3秒後にツモ牌を出す（`DRAW_DELAY`）。その間は打牌・リーチ・ツモ判断はできず（白のドラッグは可）、打牌タイマーはツモ牌を出してから数える
- 相手は手牌を持たない。山から引いた牌をそのまま捨てるだけ（テンパイすることはない）
- 流局：各自、流局巡目か山が尽きる巡のどちらか早いほう（配牌後の山 W 枚なら floor((W+1)/2) 巡）。1色は 7枚=15巡・10枚=13巡・13枚=12巡。巡目の表示と最終巡のリーチ不可もこの巡数で判定
- リーチ後のアガリ牌の確率（`src/core/settings.ts` の `RON_CHANCE` / `TSUMO_CHANCE`、どちらも25%）
  - 相手の捨て牌：25%で自分の待ち牌、75%で待ち牌以外を山の中から選んで捨てる
  - 自分のツモ：25%で待ち牌、75%で待ち牌以外を山の中から選んでツモる
  - 該当する牌が山に無ければ、山の先頭を取る。リーチ前は山の並びどおり
- 白の5枚目扱い：常に可（画面からは変更しない）
- 終了画面：紙吹雪なし。表示はリーチ時のテンパイ形（7枚）とアガリ牌の一覧だけ（残り枚数・アガリ形の分解は出さない）
  - リーチ漏れは打牌後の7枚、ノーテンリーチはテンパイに取れた打牌ごとの7枚とアガリ牌（「XXを切ればリーチできました」。フリテン・無限単騎になる打牌は「リーチ不可」と書き分ける）。リーチなしの流局は見出しのみ
- 最大枚数でないリーチ：リーチ宣言の打牌の待ち枚数（見えていない枚数の合計）が、その8枚からリーチできる打牌の中で最大でなければ局終了（同数の最大が複数あればどれでも可）。判定順はノーテン → フリテン（無限単騎含む）→ 最大枚数。終了画面は自分の形と理想の形を、アガリ牌・牌ごとの枚数・合計枚数つきで上下に並べる
- 流局巡目：初期値18。詳細設定で3〜30
- 打牌秒数：5〜60秒、初期値15秒
- 1巡目の持ち時間：15秒（打牌秒数の設定が15秒より長ければ設定値）
- 理牌：萬子・筒子・索子・發・中は常に自動理牌（打牌のたびに並べ直す）。ツモ牌は打牌まで右端に少し離して置く
- 白だけはドラッグで自由に動かせる（ツモ牌の右にも置ける）。理牌後も位置を保つ：右端→右端 / 左端→左端 / 途中→左隣の牌のすぐ右（ツモ牌は基準にしない）
- リーチ後の自分のツモ番：ボタンは「ツモ」だけ。ツモ牌をタップするとツモ切り（時間切れもツモ切り扱い）
- リーチ後の相手の捨て牌：ボタンは「ロン」だけ。緑の背景をタップするとスルー（ボタン・自分の手牌の牌・上部メニューは除く。手牌の枠の空いた部分はスルーになる。時間切れもスルー扱い）。案内文は出さない
- リーチ後のツモ／ロンボタンは、手牌と同じ幅の行の右端＝ツモ牌の置き場所の上に固定
- 対局画面のレイアウトは固定：河は1段6枚×（流局巡目÷6）段の高さを最初から確保、中央の「相手の捨て牌／警告」枠・ボタン行・手牌の幅と高さも固定し、巡目が進んでも手牌が動かない
- 終了画面は、最終局面の対局画面（操作不可）の下に続けて表示する。自動スクロールはせず対局画面が見えたまま。対局画面の中央に結果の見出し、ボタン行に「▼ 結果の詳しい内容は下へ」を出す
- 最終巡はリーチできない（ボタンは表示したまま押せない状態にする）。リーチ義務もなし
- 「リーチ」を押した後に時間切れになった場合、自動打牌はリーチ扱いにしない（その結果リーチできるテンパイならリーチ漏れ）
- 手の内に4枚ある牌は待ちに数えない（山から来ないため）
- 無限単騎の判定：白を除いた6枚が2面子になっている形
- 最善打牌：リーチできるテンパイに取れる打牌のうち、待ちの残り枚数合計が最大のもの。リーチできるテンパイに取れる打牌が無い巡は一致率の計算から除く
- 残り枚数：その時点の自分の手牌・自分の河・相手の河を見えている牌として除く
- 流局画面は中立的な表示。リーチしていればリーチ時の待ちを紹介する
